# ЭнергоГрупп 2025 — допечатная пересборка каталога

## Что получилось

`build/ЭнергоГрупп_2025_печать_PDFX-1a.pdf` — 32 страницы, PDF/X-1a, CMYK
(FOGRA39), TrimBox 210×297 мм, вылеты 4 мм, без меток обреза.
Проверяется скриптом `scripts/check_print.py` — все пункты требований
типографии проходят.

Весь наборный текст — живой вектор Onest со встроенными шрифтами.
Диаграмма роста (стр. 4), плашки таблицы (стр. 5) и маркеры-буллеты
переведены в векторные заливки.

`scripts/check_artifacts.py` сравнивает каждую собранную страницу с
оригиналом и ищет зоны потерянной детализации — так дефекты стирания
ловятся автоматически, а не глазами постранично.

## Что было не так с исходником

**1. Каталог был сведён в растр 150 dpi целиком** — вместе с текстом.
Именно текст типография и забраковала: на 150 dpi у букв рваный край.
Это устранено полностью, без участия клиента.

**2. Фотографии физически ниже печатного разрешения.** Оригиналов в
проекте нет — есть только сведённые страницы. Из 150 dpi 300 dpi не
восстановить: подложка увеличена вдвое с обработкой (слабое снятие
JPEG-артефактов, Lanczos, нерезкая маска), формально 300 dpi
выдерживается, но реальная детализация осталась прежней.

Векторизовать фотографии вместо этого не выходит, и это проверено, а не
предположено: `scripts/vectorize.py` раскладывает кадр на градиент неба и
слои силуэта, но ажурная решётка опоры ЛЭП при трассировке слипается в
пятна, а логотип «ЭНЕРГО ГРУПП» с исходных 250×135 px теряет мелкий текст
и линии опор. Результат обеих проверок —
`build/почему_нужны_исходники.jpg`. Вектором восстанавливается только
однозначная геометрия: прямоугольник, круг, буква.

**3. Файлы из `photos_hd/` — не HD.** Это копии из мессенджера
(896×1200 и 1280×960 px). В макете они дают 108–122 dpi, то есть правки
v34 сделали стр. 8, 9, 15 и 21 хуже, чем они были на исходных 150 dpi.

**4. Ошибка в прежнем ТЗ: заголовки не ExtraBold, а SemiBold.**
Проверено сравнением толщины штриха с растром. Акцентные числа
(01/02/03, 25 800 км, 317/141/71 560 м²) — действительно ExtraBold,
причём наклонные.

**5. Файлы шрифтов были неисправны.** Во всех пяти начертаниях
`fonts/Onest-*.ttf` записано одно PostScript-имя `Onest-Regular` — след
генерации из вариативного файла. ReportLab встраивал в PDF один светлый
шрифт вместо пяти, и весь каталог печатался бы Regular независимо от
вёрстки. Исправленные начертания собираются в `fonts/static/`
(`scripts/fix_fonts.py`) — их и надо использовать дальше.

## Что нужно от клиента

`assets_needed/README.md` — постраничный список из 42 кадров с превью и
минимальными размерами, `assets_needed/ОБЗОР_все_кадры.jpg` — все кадры
одним листом. Отдельно нужны векторные логотипы: знак «ЭНЕРГО ГРУПП»
(повторяется на 20+ страницах), герб фонда (стр. 2), 18 логотипов
партнёров (стр. 30), иконки персонала (стр. 5).

Главное при отправке: **исходные файлы с камеры, не через мессенджер** —
иначе снова придут те же 896×1200.

## Как пересобрать

```
pip install reportlab pypdf pikepdf pymupdf opencv-python-headless pillow fonttools numpy
apt-get install ghostscript

python3 scripts/fix_fonts.py          # начертания Onest с корректными именами
python3 scripts/make_print.py         # все 32 страницы -> PDF/X-1a
python3 scripts/make_print.py 4 5     # пересобрать только указанные страницы
python3 scripts/check_print.py        # проверка по требованиям типографии
```

Подстановка присланного фото: положить файл и указать его в спеке
страницы, затем пересобрать эту страницу.

## Инструменты

| Файл | Назначение |
|---|---|
| `specs.py` | постраничная спека: прямоугольник поиска + строки текста |
| `scripts/rebuild.py` | сборка страницы: чистая подложка + вектор |
| `scripts/textmask.py` | стирание впечатанного текста, нарезка на строки |
| `scripts/metrics.py` | базовая линия, ширина, цвет строки |
| `scripts/weight.py` | подбор начертания по плотности штриха |
| `scripts/shapes.py` | плоские заливки (столбцы, плашки) в вектор |
| `scripts/upscale.py` | подложка 150 → 300 dpi |
| `scripts/make_print.py` | вылеты, склейка, CMYK, PDF/X-1a |
| `scripts/check_print.py` | проверка готового файла |
| `scripts/analyze_quality.py` | оценка реального разрешения фото |
| `scripts/cut_previews.py` | пакет запроса исходников |
| `scripts/inspect_page.py`, `inspect_multi.py` | вычитка текста со страниц |

Геометрия: подложка 1240×1754 px @150 dpi ↔ страница 210×297 мм.
Кегль подбирается по метрикам шрифта под измеренную ширину строки —
ручных подгонок нет. У наклонного набора кегль берётся по высоте цифр:
прямоугольник строки шире самого текста и завышает размер до 15 %.

## Постраничный статус

Текст переведён в вектор на всех 32 страницах. Осталось растровым и ждёт
ассетов от клиента: знак «ЭНЕРГО ГРУПП» (почти каждая страница), герб
фонда (стр. 2), иконки персонала (стр. 5), карта России (стр. 28–29),
логотипы партнёров (стр. 30). Все фотографии ждут оригиналов.
