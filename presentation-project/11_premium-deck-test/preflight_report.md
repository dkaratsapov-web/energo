## Как проверялось

- Вёрстка — по модели слайдов: влезание, наложения, кегли, безопасное поле, ритм композиций.
- Контраст — по пикселям фона под каждой строкой (рендер без текста), худшие 10 % фона, WCAG AA.
- Печатный файл — разбор PDF: ящики, OutputIntent, версия, встроенность шрифтов, операторы цвета, прозрачность; покрытие — CMYK-рендер (99,9-й перцентиль); мелкий текст — операторы потока.
- PPTX — независимый рендер LibreOffice Impress и сравнение позиций каждой строки с PDF. Сам Microsoft PowerPoint в этой среде недоступен: вид в нём не проверен напрямую.
- Каждый слайд просмотрен глазами на листах-контактах (папка previews/).
